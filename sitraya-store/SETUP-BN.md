# Sitraya ওয়েবসাইট চালু করার গাইড (ধাপে ধাপে)

এই গাইড মেনে চললে কোনো কোড না লিখেই ওয়েবসাইটটা ইন্টারনেটে চালু করতে পারবেন। প্রতিটা ধাপ ক্রমানুসারে করুন।

---

## শুরুর আগে যা লাগবে

| জিনিস | কেন | খরচ |
|---|---|---|
| একটা ইমেইল ঠিকানা | সব অ্যাকাউন্ট খুলতে | ফ্রি |
| **GitHub** অ্যাকাউন্ট | কোড রাখার জায়গা | ফ্রি |
| **Netlify** অ্যাকাউন্ট | ওয়েবসাইট চালানোর সার্ভার | **Free** প্ল্যানে মাসে ৩০০ ক্রেডিট। ক্রেডিট শেষ হলে মাসের বাকি সময় সাইট বন্ধ ("Site not available") থাকে, তাই দোকান চালু করার আগে **Personal** (মাসে ৯ ডলার, ১,০০০ ক্রেডিট) বা **Pro** (মাসে ২০ ডলার, ৩,০০০ ক্রেডিট) নিন। আন্তর্জাতিক/ডুয়াল-কারেন্সি কার্ড লাগবে |
| **Neon** ডাটাবেস | অর্ডার, প্রোডাক্ট আর আপলোড করা ছবি সব এখানে থাকবে | ফ্রি (প্রজেক্টে ১ GB)। প্রতিটা ছবি ৫০০ KB-র নিচে রাখুন। অনেক প্রোডাক্ট/অর্ডার হলে Neon-এর পেইড প্ল্যান লাগবে |
| নিজের ডোমেইন (যেমন sitraya.com) | ঐচ্ছিক, তবে দরকারি | বছরে প্রায় ১,০০০–১,৫০০ টাকা |

> 🔒 নিরাপত্তা: GitHub, Netlify আর Neon তিনটাতেই **Two-factor authentication (2FA)** চালু করে নিন।

> 📍 **সার্ভার কোথায় থাকবে (শুরুতেই ঠিক করুন):** Netlify-র Free আর Personal প্ল্যানে সার্ভার চলে আমেরিকায় (US East, Ohio)। তখন ডাটাবেসও **AWS US East 2 (Ohio)**-তে বানান, যাতে দুটো কাছাকাছি থাকে। **Pro** প্ল্যান নিলে Netlify-তে সার্ভার **Singapore** করা যায়। তখন ডাটাবেসও **AWS Asia Pacific (Singapore)**-তে বানান, এতে বাংলাদেশ থেকে সাইট সবচেয়ে দ্রুত চলবে। ডাটাবেসের জায়গা পরে বদলানো যায় না।

> 💳 ক্রেডিট কোথায় খরচ হয়: প্রতিবার সাইট deploy করলে ১৫ ক্রেডিট, ভিজিটরদের ডেটা পাঠাতে প্রতি GB-তে ২০ ক্রেডিট, আর সার্ভার চলার সময়। Netlify → Usage-এ খরচ দেখা যায়।

## ধাপ ১: কোড GitHub-এ রাখা

1. https://github.com এ অ্যাকাউন্ট খুলুন।
2. উপরে ডানে **+** → **New repository** চাপুন।
3. নাম দিন `sitraya-store`। অবশ্যই **Private** বেছে নিন, তারপর **Create repository** চাপুন।
4. পরের পেজে **uploading an existing file** লিংকে চাপুন।
5. যে zip ফাইলটা দেওয়া হয়েছে সেটা কম্পিউটারে **Extract / Unzip** করুন।
6. খোলা ফোল্ডারের **ভেতরের সব ফাইল আর ফোল্ডার** (netlify, public, server, package.json, netlify.toml …) একসাথে টেনে ব্রাউজারের বক্সে ছেড়ে দিন।
   - ফোল্ডারটা নিজে না, তার ভেতরের জিনিসগুলো দিতে হবে।
   - `netlify.toml` আর `package.json` যেন একেবারে উপরের স্তরে থাকে।
   - `netlify` ফোল্ডারটা অবশ্যই যেন যায় (এর ভেতরেই সার্ভার)।
7. আপলোড শেষ হলে নিচে **Commit changes** চাপুন।

## ধাপ ২: ডাটাবেস বানানো (Neon)

1. https://neon.com এ যান → **Sign up** → **Continue with GitHub**।
2. **Create project** (বা প্রথমবার নিজেই এই পেজ আসবে):
   - Project name: `sitraya-db`
   - Cloud: **AWS**
   - Region: **AWS US East 2 (Ohio)**। Netlify Pro নিলে **AWS Asia Pacific 1 (Singapore)**। (উপরের 📍 নোট দেখুন)
   - **Create** চাপুন।
3. প্রজেক্টের ড্যাশবোর্ডে **Connect** বাটনে চাপুন।
4. **Connection pooling** সুইচ চালু রাখুন। নিচে `postgresql://…` দিয়ে শুরু লম্বা লেখাটা **Copy** করুন (এর মধ্যে `-pooler` লেখা থাকবে)।
5. এটা একটা নোটে রাখুন, পরের ধাপে লাগবে। **এটা পাসওয়ার্ডের মতো গোপন, কাউকে দেবেন না।**

## ধাপ ৩: Netlify-তে সাইট চালু করা

1. https://www.netlify.com এ যান → **Sign up** → **GitHub** দিয়ে অ্যাকাউন্ট খুলুন।
2. **Add new project** → **Import an existing project** → **GitHub** চাপুন। অনুমতি চাইলে দিন (শুধু `sitraya-store` রিপোজিটরি বেছে দিলেই হবে)।
3. লিস্ট থেকে `sitraya-store` বেছে নিন।
4. Build settings-এ কিছু বদলাবেন না। `netlify.toml` থেকে সব নিজে বসে যায় (Publish directory: `public`, Functions directory: `netlify/functions`)।
5. একই পেজে **Add environment variables** চাপুন, নিচের পাঁচটা যোগ করুন (Key বাঁ ঘরে, Value ডান ঘরে):

| Key | Value |
|---|---|
| `DATABASE_URL` | ধাপ ২-এ কপি করা Neon-এর `postgresql://…` লেখাটা |
| `APP_SECRET` | ৪৮ বা তার বেশি অক্ষরের এলোমেলো লেখা। যেকোনো পাসওয়ার্ড জেনারেটর দিয়ে বানান। **এটা কোথাও লিখে নিরাপদে রাখুন, পরে কখনো বদলাবেন না।** |
| `ADMIN_EMAIL` | আপনার ইমেইল, যেটা দিয়ে অ্যাডমিনে লগইন করবেন |
| `ADMIN_PASSWORD` | ১০+ অক্ষরের একটা অস্থায়ী পাসওয়ার্ড। প্রথম লগইনের পর নতুন পাসওয়ার্ড দিতে বলা হবে |
| `ADMIN_NAME` | আপনার নাম (যেমন `Rahim`) |

6. **Deploy sitraya-store** চাপুন। ১–২ মিনিট পর সবুজ **Published** দেখাবে।
7. উপরে দেখানো লিংকে (যেমন `sitraya-store.netlify.app`) চাপুন। ওয়েবসাইট খুলবে, ডেমোর মতো প্রোডাক্টসহ। ডাটাবেসের টেবিলগুলো নিজে থেকে তৈরি হয়ে যায়।

> পরে কোনো environment variable যোগ বা বদল করলে: **Project configuration → Environment variables**। বদলের পর **Deploys → Trigger deploy → Deploy project** চাপতে হয়, নাহলে নতুন মান কাজ করে না।

> **শুধু Pro প্ল্যানে:** **Project configuration → Cloud compute → Functions → Region → Configure** → **Asia Pacific (Singapore)** → **Save**, তারপর **Trigger deploy**। (ডাটাবেসও Singapore-এ থাকতে হবে।)

## ধাপ ৪: প্রথমবার অ্যাডমিনে ঢোকা

1. ঠিকানার শেষে `/admin` লিখে খুলুন, যেমন `https://sitraya-store.netlify.app/admin`।
2. ধাপ ৩-এর `ADMIN_EMAIL` আর `ADMIN_PASSWORD` দিয়ে **Sign in** করুন।
3. সাথে সাথে **নতুন পাসওয়ার্ড** চাইবে। ১০+ অক্ষরের শক্ত পাসওয়ার্ড দিন। এটা শুধু আপনি জানবেন।
4. (নিরাপত্তার জন্য) Netlify → Project configuration → Environment variables থেকে `ADMIN_PASSWORD` মুছে দিন। এটা শুধু প্রথম অ্যাকাউন্ট খোলার জন্য দরকার ছিল। আলাদা করে deploy করার দরকার নেই।

> অ্যাডমিন প্যানেলের ঠিকানা সবসময় হবে: **আপনার-সাইট/admin**। ওয়েবসাইটে এর কোনো বাটন রাখা হয়নি, তাই কাস্টমাররা দেখবে না। ঠিকানাটা বুকমার্ক করে রাখুন।

## ধাপ ৫: দোকানের তথ্য বসানো

অ্যাডমিনে বাঁ দিকের মেনু থেকে:

1. **Store Settings**:
   - ফোন, **WhatsApp নম্বর**, ইমেইল, ঠিকানা (বাংলা ও ইংরেজি) আর Website address লিখুন। WhatsApp নম্বর দিলে তবেই সাইটের হোয়াটসঅ্যাপ বাটনগুলো দেখা যাবে।
   - Social links (Facebook, Instagram …) আর ফুটারের "দোকান সম্পর্কে" লেখা দিন।
   - **Delivery charges**: ঢাকার ভেতরে/বাইরে কত টাকা, আর কত টাকার উপরে ফ্রি।
   - **Payment methods**: Cash on Delivery চালু থাকে। বিকাশ/নগদ/রকেট নিলে চালু করে নম্বর দিন। কাস্টমার টাকা পাঠিয়ে TrxID দেবে, আপনি মিলিয়ে অর্ডারকে "Paid" করবেন।
2. **Homepage & Branding**: দোকানের নাম, লোগো, স্লাইডার, ব্যানার, উপরের ঘোষণার লাইন আর বাটনের রং।
3. **Website Pages**: রিটার্ন পলিসি, প্রাইভেসি, সাইজ গাইড, প্রশ্নোত্তর। লেখাগুলো আপনার দোকানের আসল নিয়ম অনুযায়ী বদলে নিন।
4. **Products**:
   - ডেমো প্রোডাক্টগুলো এডিট করুন বা **Delete** করে নিজের প্রোডাক্ট দিন।
   - প্রতিটা প্রোডাক্টে আসল ছবি (JPG/PNG) দিন, আর "More photos"-এ আরও ছবি দিন।
   - ভিডিওর জন্য YouTube বা Facebook লিংক দিন।
5. **Categories**: নাম আর ছবি।

সব পরিবর্তন সাথে সাথে সার্ভারে সেভ হয় এবং সব ডিভাইসে দেখা যায়।

## ধাপ ৬: অর্ডার এলে ফোনে নোটিফিকেশন

যার যার ফোনে নোটিফিকেশন চান, প্রত্যেককে **নিজের ফোনে একবার** এটা করতে হবে।

### Android ফোন
1. **Chrome** দিয়ে `আপনার-সাইট/admin` খুলে লগইন করুন।
2. (ভালো হয়) Chrome-এর ⋮ মেনু → **Add to Home screen / Install app**। তাহলে অ্যাপের মতো আইকন হবে।
3. অ্যাডমিনে **Notifications** → "This phone / laptop"-এর পাশে **Turn on** → **Allow** চাপুন।
4. একটা টেস্ট নোটিফিকেশন আসবে। এরপর থেকে নতুন অর্ডার এলে নোটিফিকেশন বারে দেখাবে, অ্যাপ বন্ধ থাকলেও।
5. না এলে: ফোনের Settings → Apps → Chrome → Notifications চালু আছে কি না দেখুন। Battery saver-এ Chrome-কে "Unrestricted" করুন।

### iPhone
1. **Safari** দিয়ে `আপনার-সাইট/admin` খুলুন।
2. ঠিকানার পাশের **⋯** (তিন ডট) → **Share** → নিচে স্ক্রল করে **Add to Home Screen** (না দেখালে **View More**)। **Open as Web App** সুইচ চালু রাখুন → **Add**। (পুরোনো iOS-এ নিচের Share □↑ বাটন।)
3. হোম স্ক্রিনের নতুন আইকন থেকে খুলুন (Safari থেকে না) → লগইন → **Notifications** → **Turn on** → **Allow**।
4. iOS 16.4 বা তার নতুন ভার্সন লাগবে।

### কম্পিউটার
Chrome বা Edge-এ অ্যাডমিন খুলে একইভাবে **Turn on** চাপুন। Mac-এ System Settings → Notifications-এ গিয়ে Chrome-এর নোটিফিকেশনও চালু রাখুন।

### Telegram (ব্যাকআপ, চাইলে)
1. Telegram-এ **@BotFather** খুলুন → `/newbot` লিখুন → নাম দিন। একটা **token** পাবেন (দেখতে `123456:ABC…` এর মতো)।
2. আপনার নতুন বটটা খুলে **Start** চাপুন।
3. **@userinfobot** খুলে Start চাপুন। আপনার **Id** নম্বর দেখাবে, এটাই Chat ID।
4. অ্যাডমিন → Notifications → Telegram অংশে token আর Chat ID দিয়ে **Send a test message** চাপুন।

## ধাপ ৭: নিজের ডোমেইন যুক্ত করা

1. Netlify → প্রজেক্ট → **Domain management** → **Add a domain** → `আপনার-ডোমেইন.com` লিখে **Verify** → **Add domain**। Netlify নিজে থেকে `www.আপনার-ডোমেইন.com`-ও যোগ করে।
2. Netlify দুইভাবে সংযোগের কথা বলবে। সহজটা: যেখান থেকে ডোমেইন কিনেছেন সেখানকার DNS সেটিংসে Netlify যে `A` (মূল ডোমেইনের জন্য) আর `CNAME` (www-এর জন্য, `sitraya-store.netlify.app`) মান দেখায়, হুবহু সেটাই বসান। অথবা Netlify-র দেওয়া ৪টা **nameserver** বসান (তাহলে DNS Netlify চালাবে)।
3. ১০ মিনিট থেকে কয়েক ঘণ্টার মধ্যে চালু হবে। HTTPS (তালা চিহ্ন) Netlify নিজেই দেয়। Domain management → **HTTPS** অংশে "certificate" দেখা গেলে ঠিক আছে।
4. Project configuration → Environment variables-এ `SITE_URL` = `https://www.আপনার-ডোমেইন.com` যোগ করে **Deploys → Trigger deploy → Deploy project** চাপুন।
5. অ্যাডমিন → Store Settings → Website address-এ ডোমেইনটা লিখুন। প্রোডাক্টের শেয়ার লিংক এটা দিয়ে তৈরি হয়।
6. ডোমেইন বদলালে ফোনের নোটিফিকেশন নতুন ঠিকানায় আবার **Turn on** করতে হবে।

## ধাপ ৮: Facebook / Instagram সংযোগ

### ৮.১ Meta Pixel (সাইটের ভিজিটর আর বিক্রি Facebook-কে জানানো)
1. https://business.facebook.com → **Events Manager** → **Connect data** → **Web** → নাম দিয়ে Dataset (Pixel) তৈরি করুন।
2. ১৫–১৬ সংখ্যার **Dataset/Pixel ID** কপি করুন।
3. অ্যাডমিন → **Meta Integration** → Pixel ID বসান → **Send browser events** চালু করুন।

### ৮.২ Conversions API (সার্ভার থেকে বিক্রির তথ্য, বেশি নির্ভুল)
1. Events Manager → আপনার Dataset → **Settings** → **Conversions API** → **Generate access token**।
2. টোকেনটা অ্যাডমিন → Meta Integration → **Conversions API access token**-এ পেস্ট করুন।
   - এটা সার্ভারে এনক্রিপ্ট করে রাখা হয় এবং আর কখনো দেখানো হয় না।
3. **Send server events** চালু করুন।

### ৮.৩ ঠিকমতো যাচ্ছে কি না পরীক্ষা
1. Events Manager → **Test events** ট্যাব থেকে Test code (যেমন `TEST12345`) কপি করুন।
2. অ্যাডমিনে **Test event code**-এ বসান, **Test mode** চালু রাখুন।
3. সাইটে একটা টেস্ট অর্ডার দিন। Test events-এ **Purchase** দেখা গেলে ঠিক আছে।
4. এরপর **Test mode বন্ধ** করুন আর টেস্ট অর্ডারটা অ্যাডমিন থেকে **Cancel** করে দিন।

### ৮.৪ ডোমেইন ভেরিফাই
1. Business Settings → **Brand safety → Domains** → **Add** → www ছাড়া মূল ডোমেইনটা দিন (যেমন `sitraya.com`)।
2. **DNS TXT record** পদ্ধতি বেছে নিন।
3. দেখানো TXT রেকর্ডটা ডোমেইনের DNS-এ বসিয়ে **Verify** চাপুন।

### ৮.৫ প্রোডাক্ট ক্যাটালগ (Facebook/Instagram শপ আর বিজ্ঞাপনের জন্য)
1. **Commerce Manager** → **Catalogue** তৈরি (E-commerce) → **Data sources** → **Data feed** → **Scheduled feed**।
2. Feed URL দিন: `https://www.আপনার-ডোমেইন.com/feeds/meta-catalog.xml`
3. প্রতিদিন আপডেট (Daily) আর Currency **BDT** বেছে নিন।
4. সাইটে নতুন প্রোডাক্ট দিলে বা দাম/স্টক বদলালে ক্যাটালগেও নিজে থেকে বদলে যাবে।

> ⚠️ Facebook শুধু আসল ছবি (JPG/PNG) নেয়। ডেমো প্রোডাক্টের আঁকা ছবিগুলো (SVG) নেয় না, সেগুলোর জায়গায় কভার ছবি যাবে। তাই প্রতিটা প্রোডাক্টে নিজের ছবি আপলোড করুন।

### ৮.৬ পোস্টে প্রোডাক্টের লিংক
অ্যাডমিনে প্রোডাক্ট এডিট করলে নিচে **Share on Facebook** অংশে লিংক কপির বাটন আছে।
- লিংক দেখতে হবে এমন: `আপনার-সাইট/p/প্রোডাক্ট-আইডি`।
- Facebook বা WhatsApp-এ দিলে ছবি, নাম আর দামসহ প্রিভিউ দেখাবে।
- কেউ লিংকে চাপলে সরাসরি সেই প্রোডাক্ট খুলবে।

## ধাপ ৯: টিমের অন্যদের যুক্ত করা

1. অ্যাডমিন → **Admin Users & Roles** → **Add admin** → নাম, ইমেইল আর রোল দিন।
   - যেমন **Order Manager** শুধু অর্ডার দেখে ও আপডেট করে, প্রোডাক্টের কেনা দাম দেখে না।
2. সেভ করলে একবারের জন্য একটা **অস্থায়ী পাসওয়ার্ড** দেখাবে।
   - এটা তাকে আলাদাভাবে (গ্রুপে না) দিন।
   - প্রথম লগইনে সে নিজের পাসওয়ার্ড বানাবে।
3. কেউ চলে গেলে তার কার্ডে **Disable** চাপুন। সাথে সাথে তার সব ডিভাইস থেকে লগআউট হয়ে যাবে।
4. কেউ পাসওয়ার্ড ভুলে গেলে **Reset password** চাপুন।

রোলের অনুমতি সার্ভারে প্রতিটা কাজে যাচাই হয়, শুধু মেনু লুকানো না।

## ওয়েবসাইট আপডেট করার নিয়ম (নতুন zip এলে)

আপনার প্রোডাক্ট, অর্ডার আর সেটিংস ডাটাবেসে থাকে, তাই কোড আপডেট করলে সেগুলো মোছে না। নতুন ফিচারের জন্য ডাটাবেসে শুধু নতুন টেবিল যোগ হয়, পুরোনো কিছু বদলায় না।

1. **আগে ব্যাকআপ:** https://console.neon.tech → `sitraya-db` → বাঁ দিকে **Branches** → **New branch** → নাম দিন `backup-` আর আজকের তারিখ → **Create**। কিছু ভুল হলে এই branch থেকে আগের অবস্থায় ফেরা যায়।
2. নতুন zip **Extract** করুন, ভেতরে ঢুকুন।
3. GitHub-এ `sitraya-store` রিপোজিটরি খুলুন → **Add file** → **Upload files**।
4. ভেতরের সব ফাইল-ফোল্ডার (Ctrl + A) একসাথে টেনে ছাড়ুন। একই নামের পুরোনো ফাইলগুলো নিজে থেকে বদলে যাবে।
5. **Commit changes** চাপুন। Netlify ১–২ মিনিটের মধ্যে নিজে থেকে নতুন সাইট চালু করবে (Deploys-এ **Published** দেখাবে)।
6. ফোন আর কম্পিউটারে সাইট খুলে একবার রিফ্রেশ করুন।

## সমস্যা হলে

| কী দেখাচ্ছে | কী করবেন |
|---|---|
| "Server setting DATABASE_URL is missing" | ধাপ ২ আর ৩ আবার দেখুন: Netlify-তে `DATABASE_URL` আছে কি না। তারপর **Trigger deploy** |
| Netlify-তে "Site not available" | এই মাসের ক্রেডিট শেষ। Netlify → **Usage / Billing** থেকে Personal বা Pro নিন |
| "APP_SECRET is missing" বা "must be at least 32 characters" | ধাপ ৩-এর APP_SECRET ঠিক করে Trigger deploy |
| "APP_SECRET was changed" | পুরোনো APP_SECRET-টা আবার বসিয়ে Trigger deploy করুন। নতুন secret দিলে Meta/Telegram টোকেন আর ফোনের নোটিফিকেশন আবার সেট করতে হবে |
| "No admin exists yet. Set ADMIN_EMAIL and ADMIN_PASSWORD…" | ADMIN_EMAIL আর ADMIN_PASSWORD (১০+ অক্ষর) যোগ করে Trigger deploy |
| পাসওয়ার্ড ভুলে গেছেন (মালিক) | https://console.neon.tech → `sitraya-db` → **SQL Editor**-এ `delete from admins;` চালান (টিমের সব অ্যাডমিন মুছে যাবে, পরে আবার যোগ করতে হবে)। তারপর Netlify-তে `ADMIN_PASSWORD` আবার যোগ করে **Trigger deploy** করুন এবং লগইন করুন। অর্ডার/প্রোডাক্ট মুছবে না |
| ফোনে নোটিফিকেশন আসে না | Notifications পেজে **Send a test** চাপুন। Turn off করে আবার Turn on করুন। Android-এ Chrome-এর নোটিফিকেশন আর ব্যাটারি সেটিংস দেখুন |
| "Too many attempts" | নিরাপত্তার জন্য ১৫ মিনিট অপেক্ষা করুন |
| অর্ডার দিতে গিয়ে "stock changed" | ওই সাইজ/রং শেষ। অ্যাডমিনে স্টক দেখুন |

**ব্যাকআপ:** Neon আগের কোনো সময়ের অবস্থায় ফিরে যেতে পারে (Free প্ল্যানে অল্প সময়ের জন্য, Neon → **Backup & restore**)। বিক্রি বাড়লে Neon-এর পেইড প্ল্যানে বেশি দিনের ব্যাকআপ নিন। মাসে একবার Neon-এর **Backup & restore** দেখে নিন।
